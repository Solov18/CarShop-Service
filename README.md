Описание выполненной работы
Проект включает в себя следующие ключевые компоненты:

Контроллеры:
OrderController: Управляет созданием, обновлением и отменой заказов. Этот класс управляет списком заказов, позволяет изменять статус заказа и отменять его. Также предоставляет возможности для фильтрации заказов по дате, клиенту, статусу и автомобилю.

CarController: Отвечает за управление автомобилями, включая добавление новых автомобилей, их удаление и обновление информации. Также поддерживает сохранение и загрузку списка автомобилей из файла. Предоставляет возможности для поиска и фильтрации автомобилей по различным критериям, таким как цена и год выпуска.

UserController: Управляет пользователями системы, включая регистрацию новых пользователей и их аутентификацию. Этот класс также позволяет фильтровать и сортировать клиентов по различным критериям, таким как имя, контактная информация и количество заказов. Он также обеспечивает проверку существования пользователя по имени и увеличение количества заказов для клиентов.

Модели:
Order, Car, User, Client, Admin, Manager: Представляют данные и реализуют логику, связанную с заказами, автомобилями и пользователями.

Тесты:
Написаны юнит-тесты для проверки функциональности контроллеров и их взаимодействия.

Логи:
Реализована простая система аудит-логов для отслеживания действий пользователей.

Инструменты покрытия кода:
JaCoCo: Использовался для анализа покрытия тестами. Этот инструмент помогает оценить, насколько полно тесты покрывают код, что позволяет улучшить качество тестов и надежность кода.

Используемый стек
Язык программирования: Java
Фреймворк для тестирования: JUnit
Инструмент покрытия кода: JaCoCo
Система контроля версий: Git
Среда разработки: IntelliJ IDEA
Команды
Запуск приложения:
Скомпилируйте и запустите проект. Создание пользователей: Для входа в систему можно использовать предустановленные данные: Admin:("admin", "123") Также доступна функция регистрации новых пользователей через интерфейс приложения.

Работа с автомобилями: В меню приложения, нажав на цифру 6, можно загрузить список автомобилей из файла auto. Это полезно для тестирования программы и проверки функциональности работы с данными о автомобилях.

Запуск тестов:
Тесты можно запустить с помощью Maven: mvn test

Генерация отчета о покрытии кода:
Отчет можно найти в папке target/site/jacoco
